date: 2026-11-03

An R package for sensitivity analysis of linear regression coefficients when omitted variables may bias them. It reports how far a coefficient can move as the no-omitted-variables assumption is relaxed, the breakdown point at which a conclusion stops holding, and plots of both, following Diegert, Masten and Poirier (2026), Oster (2019), and Masten and Poirier (2026).

Install from CRAN with `install.packages("regsensitivity")`.
